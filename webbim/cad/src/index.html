      Where the modelling happens

      This page builds the geometry itself, and needs nothing else to do it. A server does the same work with more room — it keeps the whole document natively and can write files straight to disk.

      Leave this alone and everything happens in the page, which is what most work wants. Point it at a server and the same interface uses that instead — nothing else about the document changes.

      Model file — .model.json

      The parametric model — every feature, its arguments and its references. Paste one in and it is rebuilt.
